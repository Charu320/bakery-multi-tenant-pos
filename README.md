# Multi-Outlet Bakery Management System

A production-ready web application built for managing orders, billing,
GST, and kitchen operations across multiple bakery outlets.

##  Features
- Role-based access (Admin / Manager / Kitchen)
- Multi-outlet support with outlet switcher
- GST configuration per outlet
- Discount & balance management
- Real-time kitchen order screen
- Printable bill & detail slips
- Secure authentication
- Cloud deployment

## Tech Stack
- React + TypeScript
- Tailwind CSS
- Supabase (Auth, DB, Storage, Realtime)
- Netlify
- TanStack Query

## Architecture
- Single codebase for all outlets
- Outlet-scoped data access
- Context-based state management
- Realtime subscriptions for kitchen
